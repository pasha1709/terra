# Customer-care panorama

`packed-cup-panorama.png` is the standalone photograph used by the customer-care banner.
Generated with the built-in imagegen tool from `packed-cup.png`; the supplied layout was used only as a composition reference. Original preserved.

Add space and pale stone tabletop around the box, eucalyptus on the left, peach plates and lavender linen on the right. Natural warm light. No text, UI, empty bands, distortion or blurred copies. Match the reference banner's scale.

Desktop uses a 5.3:1 viewport through the central composition. Mobile shows the complete panoramic source.
